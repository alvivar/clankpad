Clankpad — VS Code palette proposal

Three palettes copied from VS Code's built-in themes. Clankpad follows the Windows light/dark setting, so a complete proposal is one dark palette plus Light Modern.

Status: A (Dark Modern) is the dark theme since commit 5185c21. B and C are not implemented; light mode still uses the original palette. The mockups show the proposal, so a few details differ from what shipped (see notes).

A · Dark Modern B · Dark+ (classic) C · Light Modern Shipped vs. proposal

A · Dark Modernshipped

VS Code's current default dark theme. Neutral, nearly black greys, a blue top border on the active tab, and blue accents only where they mark focus or the primary action.

B · Dark+ (classic)

The pre-2023 default dark theme. Inactive tabs are lighter than the tab bar, active tabs have no colored indicator, and the blue is slightly darker.

C · Light Modernpairs with A

VS Code's default light theme, shown here as a light-mode proposal that is not yet implemented.

Shipped vs. proposal (A · Dark Modern)

  • Where: an explicit dark ColorScheme plus TextSelectionThemeData in lib/main.dart. Dark find-match colors live in lib/models/editor_tab.dart because their roles are shared with other widgets.
  • Surfaces: the Ctrl+K popup and diff panel use #252526, the find bar uses #202020, and dropdown menus use the editor background #1F1F1F.
  • Error banner: #252526 / #CCCCCC in both modes, with the terracotta #D99B79 accent instead of VS Code red.
  • Diff: the existing green and the terracotta deleted-word highlight were kept; the mockup shows VS Code's green and red.
  • Layout unchanged: the active-tab indicator stays on the bottom edge, and the dirty dot keeps the accent color.
